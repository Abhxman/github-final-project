# Simple Interest Calculator

This project contains a simple interest calculator implemented using a Bash script.

## Description

The Simple Interest Calculator calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

**Formula:**

Simple Interest = (Principal × Rate × Time) / 100

## Usage

Run the Bash script:

```bash
bash simple-interest.sh
```

Enter the following values when prompted:
- Principal amount
- Annual rate of interest (percentage)
- Time period (in years)

The script displays the calculated simple interest and total amount.
